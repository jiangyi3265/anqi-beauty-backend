# 数据库脚本

本目录集中保存暨美丽项目的 MySQL 初始化和业务菜单脚本。新开发库按以下顺序导入：

1. `ry_20250522.sql`：若依后端基础表、权限和初始化数据。
2. `anqi-deployment-menus.sql`：暨美丽管理后台菜单与权限初始化数据。
3. `anqi-staff-scheduling.sql`：“员工排班”菜单及 `anqi:staff:edit` 操作权限。
4. `anqi-income-config.sql`：“收益管理”菜单及 `anqi:earnings:edit` 收益规则配置权限。

第 3、4 步依赖第 2 步创建的“暨美丽”父菜单；这两个脚本可重复执行，不会覆盖已有菜单，也不会给其他角色授权，已有数据库升级时只需执行这两步。

执行前请先创建目标数据库，并根据部署环境配置数据库连接信息。脚本开头已声明 `SET NAMES utf8mb4`。脚本只包含结构和初始化数据，不包含任何数据库密码。

公开仓库的管理员密码为空，不能直接登录；也没有固定的新增用户初始密码。首次导入后，请使用本地 BCrypt 工具生成自己的管理员密码哈希（例如 `htpasswd -nBC 12 admin`，交互输入新密码后取冒号后的哈希），通过数据库管理工具更新 `sys_user` 中 `user_id=1` 的 `password` 字段。登录后在参数设置中配置新增用户初始密码，或创建用户时单独指定密码。真实密码及生成的哈希均不要保存到仓库。

这些初始化脚本会重建基础表，只能导入新开发库；不能用于覆盖现有业务数据库。
